# Vimarsh
AI-Powered Multi-Personality Conversational Wisdom Platform.

Vimarsh enables authentic dialogues with 25 historical personalities across 6 knowledge domains, powered by Azure OpenAI.

## Quick Start
```bash
# Install dependencies
cd frontend && npm install
cd ../backend && pip install -r requirements.txt

# Run locally
# In frontend:
npm start

# In backend:
func start
```

> For full architectural details, deployment instructions, and API references, please see the `specs/` directory.
