## Introduction

Welcome to the comprehensive User Settings feature! This unified settings hub gives you complete control over your wisdom journey with Vimarsh. Customize your experience, manage notifications, control your data privacy, and track your spiritual growth—all in one place.

### What's New?

- **Centralized Control**: All settings in one intuitive interface
- **Journey Insights**: View your progress, streak, and achievements
- **AI Transparency**: See exactly how your AI usage is calculated
- **Privacy Controls**: Granular control over data collection and retention

## Accessing Settings

### From Any Page

1. **Desktop**: Look for the ⚙️ Settings icon in the top-right header navigation

3. **Direct URL**: Navigate to `/settings` in your browser

## Notifications Tab

Configure when and how Vimarsh reaches out to nurture your wisdom practice.

### Daily Wisdom

**Master Toggle**
- Enable/disable all daily wisdom notifications
- Preferred time picker (24-hour format)
- **Time Presets**: Morning (9:00), Afternoon (14:00), Evening (18:00), Night (21:00)

**How It Works:** Receive a profound quote from a random personality at your chosen time, deepening daily contemplation.

### Timezone

**9 Major Timezones:**
- UTC (Coordinated Universal Time)
- America/New_York (EST/EDT)
- America/Los_Angeles (PST/PDT)
- Europe/London (GMT/BST)
- Europe/Paris (CET/CEST)
- Asia/Kolkata (IST)
- Asia/Tokyo (JST)
- Australia/Sydney (AEST/AEDT)
- Asia/Shanghai (CST)

**Why It Matters:** Ensures notifications arrive at the right time in your location.

### Quiet Hours

**Configuration:**
- Enable/disable quiet hours
- Start time (e.g., 22:00)
- End time (e.g., 07:00)

**Behavior:** Notifications are suppressed during quiet hours, respecting your rest and focus time.

**Edge Case:** Quiet hours can span midnight (e.g., 22:00 to 07:00).

### Notification Types

**4 Granular Controls:**

1. **Daily Wisdom** 🧘
   - Daily quotes from personalities
   - Based on preferred time setting

2. **Streak Reminders** 🔥
   - Gentle nudges if you haven't engaged today
   - Helps maintain your conversation streak
   - Sent in the evening if no activity

3. **Achievements** 🏆
   - Celebrations when you unlock milestones
   - Examples: "7-Day Streak", "10 Conversations", "Domain Explorer"

4. **Weekly Summary** 📊
   - Sunday recap of your week's wisdom journey
   - Stats, top personalities, insights discovered

**Best Practice:** Enable types that support your practice without overwhelming you.

### Test Notification

**Try It Out:**
1. Click "Send Test Notification" button
2. Browser requests notification permission (first time)
3. Receive sample notification instantly

**Troubleshooting:**
- If permission denied, check browser settings
- Ensure notifications enabled at OS level
- PWA users: Check app notification settings

## Memory & Privacy Tab

Control how Vimarsh remembers you and manages your data with transparency and GDPR compliance.

### Memory Features

**4 Toggles:**

1. **Remember Conversations** 🗣️
   - Stores conversation history for context
   - Enables "Memory Dashboard" feature
   - Can be disabled for ephemeral conversations

2. **Connect Insights** 🔗
   - Links patterns across conversations
   - Creates deeper understanding of your journey
   - Powers personalized wisdom recommendations

3. **Track Emotions** 💚
   - Analyzes emotional themes in your queries
   - Helps personalities respond empathetically
   - Optional for those seeking emotional privacy

4. **Suggest Topics** 💡
   - Proactively suggests related wisdom topics
   - Based on your interests and conversation history
   - Can be disabled for user-driven exploration only

### Privacy Mode

**3 Levels:**

1. **Standard** 🌟 (Default)
   - Full feature access
   - Conversation history stored
   - Insights and connections enabled
   - Personalization active

2. **Private** 🔒
   - Limited context retrieval (last 3 conversations only)
   - No long-term pattern analysis
   - Reduced personalization
   - Suitable for sensitive topics

3. **Minimal** 🚫
   - No storage of conversations
   - No memory or insights
   - Ephemeral interactions only
   - Maximum privacy, minimum features

**Impact Matrix:**

| Feature | Standard | Private | Minimal |
|---------|----------|---------|---------|
| Conversation Storage | ✓ | Limited | ✗ |
| Memory Dashboard | ✓ | Partial | ✗ |
| Insights Discovery | ✓ | ✗ | ✗ |
| Topic Suggestions | ✓ | ✗ | ✗ |
| Personalization | Full | Limited | None |

### Data Transparency

**2 Consent Controls:**

1. **Allow Analytics** 📈
   - Anonymous usage data for platform improvement
   - No personal information shared
   - Powers feature prioritization
   - **Default:** Enabled (opt-out anytime)

2. **Allow Research** 🔬
   - Anonymized conversation patterns for wisdom research
   - Advances AI + spirituality understanding
   - Strictly academic, never commercial
   - **Default:** Disabled (opt-in only)

**GDPR Compliance:** Your data, your choice. Change anytime with immediate effect.

### Data Retention

**Retention Period Selector:**
- **30 days**: Minimal footprint, recent context only
- **90 days** (Default): Balanced history and privacy
- **180 days**: Medium-term journey tracking
- **365 days**: Full-year reflection and growth analysis

**How It Works:** Conversations older than your selected period are automatically deleted. Bookmarked conversations are exempt.

### Data Management

**Export Your Data** 📥
- GDPR-compliant JSON export
- Includes: conversations, preferences, bookmarks, wisdom journal
- Metadata: export timestamp, version, item counts
- Async job for large datasets (email notification when ready)

**Clear History** 🗑️
- Permanently delete all conversation history
- **Warning:** This action cannot be undone
- Requires confirmation modal
- Preferences and account data retained

**Best Practice:** Export before clearing for your records.

## Auto-Save Feature

### How It Works

**Intelligent Auto-Save:**
- **500ms Debounce**: Waits 500ms after your last change before saving
- **Optimistic UI**: Changes appear instantly, save happens in background
- **Visual Feedback**: Toast notifications confirm save status

**Status Indicators:**

1. **Saving...** ⏳
   - Appears 500ms after change
   - Spinner icon + gray text
   - Request in flight

2. **Saved** ✓
   - Green checkmark icon
   - Confirms successful save
   - Disappears after 3 seconds

3. **Failed to Save** ✗
   - Red error icon
   - "Retry" button appears
   - Error message displayed

### What Gets Auto-Saved

**Immediate Auto-Save:**
- Conversation style changes
- Language and formality preferences
- Favorite personalities (add/remove)
- Notification settings (all toggles and times)
- Memory feature toggles
- Privacy mode changes
- Theme and appearance settings

**Manual Save Required:**
- Account deletion (requires explicit confirmation)
- Data export (triggered by button click)
- Clear history (requires confirmation modal)

### Troubleshooting Auto-Save

**If Auto-Save Fails:**
1. Check internet connection
2. Look for error toast with details
3. Click "Retry" button if available
4. Refresh page to see last saved state
5. Contact support if persistent

**Data Consistency:**
- Last successful save always preserved
- Failed saves don't overwrite good data
- Optimistic updates revert on error

## Troubleshooting

### Settings Not Loading

**Symptoms:** Blank page, loading spinner doesn't disappear

**Solutions:**
1. Hard refresh: Ctrl+F5 (Windows) or Cmd+Shift+R (Mac)
2. Clear browser cache and cookies
3. Check Application Insights for errors
4. Try incognito/private browsing mode
5. Contact support with error details

### Preferences Not Saving

**Symptoms:** Changes revert after page refresh

**Solutions:**
1. Check "Saved" toast appears after changes
2. Verify internet connection active
3. Check browser console for errors
4. Ensure cookies enabled
5. Try different browser

### Notifications Not Working

**Symptoms:** No notifications despite enabled settings

**Solutions:**
1. Check browser notification permissions
2. Verify OS notification settings
3. Ensure quiet hours not active
4. Test with "Send Test Notification" button
5. Check timezone setting is correct

### Auto-Save Constantly Failing

**Symptoms:** Persistent "Failed to Save" errors

**Solutions:**
1. Check Azure Functions status page
2. Verify JWT token not expired (re-login)
3. Check Cosmos DB connectivity
4. Review Application Insights logs
5. Contact support with timestamp and error

## Privacy & Data

### Data Storage

**What We Store:**
- User preferences (experience, notifications, memory)
- Conversation history (respects retention settings)
- Journey statistics (streak, achievements)
- Usage analytics (if consented)

**Where It's Stored:**
- Azure Cosmos DB (vimarsh-db database)
- Containers: user_preferences, engagement_tracking, conversation_memory
- Region: West US (configurable for compliance)

### Data Security

**Encryption:**
- At rest: Azure Cosmos DB encryption
- In transit: HTTPS/TLS 1.3
- Authentication: JWT + Microsoft Entra ID

**Access Control:**
- User-specific partition keys
- Role-based access control (RBAC)
- Audit logging enabled

### GDPR Rights

**Your Rights:**
1. **Right to Access**: Export all your data anytime
2. **Right to Rectification**: Edit preferences freely
3. **Right to Erasure**: Delete account and all data
4. **Right to Portability**: JSON export format
5. **Right to Object**: Opt-out of analytics/research

**Exercising Rights:**
- Access: Use "Export Data" button
- Rectification: Edit settings directly
- Erasure: Use "Delete Account" button
- Portability: Download JSON export
- Object: Toggle analytics/research consent

### Data Retention Policy

**Active Accounts:**
- Preferences: Retained indefinitely (while account active)
- Conversations: Based on your retention setting (30-365 days)
- Analytics: Aggregated, anonymized after 13 months

**Deleted Accounts:**
- 30-day soft delete (recovery possible)
- After 30 days: Permanent deletion
- Anonymized analytics retained (no personal info)
